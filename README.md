# りこんの窓口 コミュニティ

離婚を考えはじめた方、手続き中の方、その後の暮らしを歩む方が、匿名で気持ちや経験を分かち合うためのコミュニティサイトです。

## 現在の実装範囲

- WebGLを使ったレスポンシブな公開トップ
- 6つの匿名相談部屋と、検索・カテゴリー絞り込み
- 参加前の部屋詳細と、会員限定コンテンツの境界
- この場所について、安全ガイド、緊急窓口、規約、プライバシー
- 「りこんの窓口」「支援ナビ」への連携導線
- LINE／メール認証の接続前UI

## 技術構成

- Next.js 16 / React 19 / TypeScript
- Tailwind CSS 4（ベース）＋サイト固有CSS
- Three.js / React Three Fiber
- Vercel

## ローカル実行

```bash
pnpm install
pnpm dev
```

品質確認は `pnpm lint` と `pnpm build` で行います。
